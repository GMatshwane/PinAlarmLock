# CI Trim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop building throwaway-signed AABs on PRs and `main`; keep `quality` as the merge gate and leave real AABs to **Play release**.

**Architecture:** Delete the `play-bundle` job from `.github/workflows/ci.yml`. Remove the `ALLOW_CI_SIGNING` escape hatch from Gradle, but keep the fail-fast if `keystore.properties` still points at the leftover CI throwaway key. Update Play operator docs so they no longer describe `app-release-ci`.

**Tech Stack:** GitHub Actions, Gradle Kotlin DSL, Android App Bundle signing via `keystore.properties`.

## Global Constraints

- Work on branch `ci-trim` (or another non-`main` branch). Never commit to `main` locally.
- Spec: `docs/superpowers/specs/2026-09-18-ci-trim-design.md`
- Do not modify `.github/workflows/play-release.yml` or `.github/workflows/pages.yml`
- Do not path-filter, rename, or shrink the `quality` job
- Do not change Android product code, `scripts/create-upload-keystore.sh`, or `.gitignore`
- Keep `ci-keystore/` ignored
- `quality` must keep running `./gradlew --no-daemon :app:ktlintCheck :app:lintDebug :app:testDebugUnitTest :app:assembleDebug`

## File structure

| File | Responsibility |
| --- | --- |
| `.github/workflows/ci.yml` | PR/`main` quality gate only |
| `app/build.gradle.kts` | Reject leftover CI throwaway keys; no `ALLOW_CI_SIGNING` |
| `docs/play/README.md` | Operator docs matching the workflows |

Do not create new files besides this plan.

- [ ] **Step 2: Delete the escape hatch, keep the hard fail**

In `app/build.gradle.kts`, replace this block:

```kotlin
val allowCiSigning = providers.environmentVariable("ALLOW_CI_SIGNING").orNull == "true"
val releaseStoreFile = keystoreProperties.getProperty("storeFile").orEmpty()
val releaseKeyAlias = keystoreProperties.getProperty("keyAlias").orEmpty()
val isCiThrowawayKey =
    releaseStoreFile.contains("ci-keystore") || releaseKeyAlias == "ci"
tasks.matching {
    it.name == "signReleaseBundle" || it.name == "packageRelease" || it.name == "assembleRelease"
}.configureEach {
    doFirst {
        if (isCiThrowawayKey && !allowCiSigning) {
            throw GradleException(
                "keystore.properties points at the CI throwaway key, which expires in 2 days. " +
                    "Play Console rejects that certificate. Create an upload key with " +
                    "./scripts/create-upload-keystore.sh and rebuild. CI may set ALLOW_CI_SIGNING=true."
            )
        }
    }
}
```

with:

```kotlin
val releaseStoreFile = keystoreProperties.getProperty("storeFile").orEmpty()
val releaseKeyAlias = keystoreProperties.getProperty("keyAlias").orEmpty()

    releaseStoreFile.contains("ci-keystore") || releaseKeyAlias == "ci"
```

- [ ] **Step 5: Fail-fast verification with a leftover CI keystore**

This must restore any existing `keystore.properties`. Run from the repo root:

```bash
set -euo pipefail
restore() {
  if [[ -f /tmp/pinalarmlock-keystore.properties.bak ]]; then
    mv /tmp/pinalarmlock-keystore.properties.bak keystore.properties
  else
    rm -f keystore.properties
  fi
}
trap restore EXIT
if [[ -f keystore.properties ]]; then
  cp keystore.properties /tmp/pinalarmlock-keystore.properties.bak
fi
printf '%s\n' \
  'storeFile=ci-keystore/ci.jks' \
  'storePassword=android' \
  'keyAlias=ci' \
  'keyPassword=android' > keystore.properties
set +e
ALLOW_CI_SIGNING=true ./gradlew --no-daemon :app:bundleRelease
status=$?
set -e
if [[ "$status" -eq 0 ]]; then
  echo "expected bundleRelease to fail for a leftover CI key" >&2
  exit 1
fi
```

Expected: non-zero Gradle exit. Output contains `keystore.properties points at the CI throwaway key`. Setting `ALLOW_CI_SIGNING=true` must not bypass the failure.
